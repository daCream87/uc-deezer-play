# Changelog

## v0.3.1

### Added
- **Power button:** The physical Remote 3 Power button now first stops the active Music Assistant queue and then powers off / puts the selected playback device into standby when the player supports power control.
- **Stop button:** The physical Remote 3 Stop button explicitly stops the active Music Assistant playback queue without powering off the playback device.
- **Simplified login:** Music Play can now be configured with a Music Assistant username and password instead of requiring the user to manually find and copy a Long-Lived Access Token. After successful authentication, Music Play creates and stores a Long-Lived Token for subsequent connections. Manual token entry remains available as a fallback.
